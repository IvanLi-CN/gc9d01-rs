# STM32G4 GC9D01 90° Complex Patterns with RGB565 Frame Buffer

这个示例演示了使用RGB565帧缓冲区进行GC9D01显示器渲染的增强版本。

## 主要特性

### RGB565帧缓冲区
- **完整屏幕缓冲区**: 使用与屏幕分辨率相同的RGB565缓冲区 (160×40像素 = 6400像素)
- **内存中渲染**: 所有图形操作都在内存中的帧缓冲区中进行
- **批量刷新**: 完成整个图案后一次性刷新到显示器
- **坐标变换**: 自动处理90°+180°旋转的坐标变换

### 性能优化
- **减少SPI通信**: 每个图案只需要一次完整的屏幕刷新
- **批量传输**: 使用1KB块进行高效的SPI数据传输
- **内存操作**: 快速的内存操作替代多次SPI调用

### 帧缓冲区函数

#### `clear_frame_buffer(color: u16)`
用指定颜色清空整个帧缓冲区。

#### `set_pixel_in_buffer(x: u16, y: u16, color: u16)`
在帧缓冲区中设置单个像素的颜色。

#### `fill_rect_in_buffer(x0: u16, y0: u16, x1: u16, y1: u16, color: u16)`
在帧缓冲区中填充矩形区域。

#### `flush_frame_buffer(spi, cs, dc)`
将整个帧缓冲区刷新到显示器，包含坐标变换。

## 显示图案

1. **基础填充测试**: 红、绿、蓝全屏填充
2. **多色棋盘格**: 8×2块的复杂棋盘格图案
3. **渐变条纹**: 垂直渐变色条纹
4. **同心矩形**: 从外到内的彩色矩形边框
5. **对角线图案**: 多色对角线交叉图案
6. **螺旋图案**: 彩色方形螺旋图案

## 技术细节

### 内存使用
- 帧缓冲区大小: 6400像素 × 2字节 = 12.8KB
- 临时字节缓冲区: 12.8KB (用于SPI传输)
- 总内存使用: ~25.6KB

### 坐标变换
逻辑坐标(x,y) → 物理坐标(39-y, 159-x)
这个变换组合了90°旋转和180°翻转，适配用户的显示器配置。

### SPI传输优化
- 1KB块大小的批量传输
- 进度日志记录(每25%显示进度)
- 高效的字节序列化

## 构建和运行

```bash
cd examples/stm32g4-160-40-direct-spi-90-complex-patterns
cargo clean
cargo run
```

## 硬件配置

- **目标**: STM32G4系列微控制器
- **显示器**: GC9D01 (40×160物理像素，旋转90°使用)
- **接口**: SPI (16MHz)
- **引脚配置**:
  - SCK: PB3
  - MOSI: PA7
  - CS: PA4
  - DC: PB0
  - RST: PC4

## 优势

1. **更流畅的动画**: 避免了逐像素SPI传输的闪烁
2. **更高的性能**: 减少SPI通信开销
3. **更好的图案质量**: 完整图案一次性显示
4. **灵活的渲染**: 支持复杂的图形操作
5. **调试友好**: 详细的进度日志和性能指标
